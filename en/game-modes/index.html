NOT EVERY RUN HAS THE SAME PURPOSE

Choose a mode for what you want to practice

Start with one question

Still thinking about which key to press? Start with Low Cortisol. Comfortable with doorways and ready for a longer search? Main is the reference with a target of 13. Want to explore a variant? Read Baltazar’s instructions. Triple Trouble explicitly warns newcomers: you do not need to start with the toughest option.

Images establish the menu wording, not every mode’s behavior. They also do not establish that modes must be unlocked in sequence. Use the selector’s NEXT button when looking for the second screen.

01

Low Cortisol · build confidence

The menu presents it as an easier option. The host shows a counter of 3, but this may be a stage of the run: do not treat 3/3 as proof of completion. A useful practice goal is completing an entry, interaction and return loop before focusing on speed. Do not apply its target to other modes.

02

Main · organize a longer search

The selection screen specifies 13 chocolates and an exit. Keep track of checked rooms and watch the HUD after each pickup. The author’s photos include partial counts such as 3/13 and 6/13; these illustrate progress, not a numbered route or coordinates.

03

Baltazar · read before assuming

The second screen names Baltazar Wilton Wölken. That identifies the option but does not establish a speed, collection target or ability. On entering, read the run’s own objective and adjust the manual checklist if useful.

04

Triple Trouble · arrive prepared

Its text indicates higher difficulty and advises against starting here. We recommend first practicing item selection and junction navigation. Three faces in the illustration are not enough to infer a fixed pursuer count, spawn patterns or exact rules.

Difficulty does not mean the same strategy

Before attributing a defeat to the mode, review what happened: did you select the wrong item, lose a junction or overlook the counter? Recording one decision to change gives the next attempt a purpose. Do not treat a comment’s claimed invulnerable spot as a substitute for learning the controls.

Not sure what to practice before increasing difficulty? Use the guide’s four-step self-check.
